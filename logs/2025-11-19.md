# 2025-11-19 作業ログ：Day 2

## 1. やろうとした事
- KAGOYA VPS (AlmaLinux 9) を構築し、Red Hat Enterprise Linux 9 (RHEL9) に変換する。
- インスタンス名: node1

## 2. 実行したコマンド
- `dnf -y update`
- `convert2rhel` のインストールと実行

## 3. 起きた事（エラーと解決）
### トラブル1：dnfが失敗する
- **事象:** `curl` コマンドでURLを貼り付けた際、改行が含まれてしまい、壊れた `.repo` ファイルが作成された。
- **解決:** `rm` で壊れたファイルを削除し、正しいURL（Red Hat公式CDN）で再取得した。

### トラブル2：カーネルバージョンの不一致
- **事象:** `convert2rhel` 実行時、`Invalid kernel version` エラーが発生。
- **原因:** `dnf update` で最新カーネルが入ったが、再起動していなかったため、古いカーネルで動いていた。
- **解決:** `reboot` を実行し、最新カーネルで起動し直してから変換コマンドを実行して成功した。

## 4. 成果
- KAGOYA VPS上で純正の `Red Hat Enterprise Linux release 9.7 (Plow)` が稼働した。
- ISOアップロードを使わず、テンプレート(AlmaLinux)からの変換という「最短ルート」を確立できた。
